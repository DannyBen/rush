NAME
==================================================

**rush completions** - Generate a shell completion script

SYNOPSIS
==================================================

**rush completions** [SHELL]

DESCRIPTION
==================================================

Generate a shell completion script


ARGUMENTS
==================================================

SHELL
--------------------------------------------------

Shell to generate completions for

- Default Value: **bash**
- Allowed Values: **bash, zsh**
